# M D L U KAVISHKA — Portfolio

A minimal, light, motion-heavy full-stack developer portfolio inspired by the supplied reference screenshots.

## Stack
- Next.js 15 + React 19 + TypeScript
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Lucide React
- Custom responsive CSS

## Run
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before deployment
1. Replace the portrait URL in `app/page.tsx` with your own large portrait.
2. Replace placeholder GitHub / LinkedIn URLs.
3. Replace project demo/repository URLs.
4. Replace `public/resume.pdf` with your final CV.
5. Connect the contact form to your preferred API/email service.

## Motion
- Full-screen intro loader
- Hero staggered typography reveal
- Image entrance + parallax
- Magnetic buttons
- Custom cursor
- Scroll-triggered section/text/card reveals from alternating directions
- Animated skill proficiency bars
- Infinite marquee
- Hover motion on projects, articles and links
- Smooth Lenis scrolling
